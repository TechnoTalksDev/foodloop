# Cart System Integration

This documents the cart system integration with Supabase backend.

## Database Schema

The cart system uses the `cart_items` table with the following structure:

```sql
create table public.cart_items (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  user_id uuid null,
  product_id bigint null,
  quantity bigint null default '1'::bigint,
  constraint cart_pkey primary key (id),
  constraint cart_items_product_id_fkey foreign KEY (product_id) references product (id) on update CASCADE on delete CASCADE,
  constraint cart_items_user_id_fkey foreign KEY (user_id) references users (id)
) TABLESPACE pg_default;
```

## Implementation

### 1. Cart Context Provider (`context/cart-provider.tsx`)

- Manages global cart state
- Provides functions for cart operations:
  - `addToCart(productId, quantity)` - Adds item to cart or updates existing quantity
  - `updateCartItem(cartItemId, quantity)` - Updates quantity of existing cart item
  - `removeFromCart(cartItemId)` - Removes item from cart
  - `getCartItemByProductId(productId)` - Gets cart item for a specific product
  - `getTotalItems()` - Returns total number of items in cart
  - `getTotalPrice()` - Returns total price of all items in cart
  - `refreshCart()` - Refreshes cart data from database

### 2. Product Detail Screen Updates (`app/(protected)/product/[id].tsx`)

- Integrates with cart context
- Shows different UI states:
  - **Not in cart**: Shows "Add to Cart" button
  - **In cart**: Shows "Update Cart" and "Remove" buttons
- Provides quantity selector
- Shows loading states and success/error alerts
- Automatically sets quantity to existing cart item quantity when present

### 3. Cart Screen Updates (`app/(protected)/(tabs)/cart.tsx`)

- Displays all cart items with product details
- Shows product images, names, prices, and business information
- Provides quantity controls for each item
- Shows individual item subtotals and total cart value
- Includes environmental impact messaging
- Provides remove functionality with confirmation
- Shows empty state when cart is empty
- Supports pull-to-refresh

### 4. Cart Badge in Marketplace

- Shows cart item count in a red badge on the cart icon
- Updates automatically when cart changes
- Shows "99+" for counts over 99

## Features

### User Experience
- **Smart quantity handling**: If item already exists in cart, adding more increases the quantity
- **Visual feedback**: Loading states, success messages, and error handling
- **Confirmation dialogs**: Asks for confirmation before removing items
- **Real-time updates**: Cart badge and totals update immediately
- **Pull-to-refresh**: Users can refresh cart data by pulling down

### Data Management
- **Automatic sync**: Cart state syncs with database on every operation
- **User isolation**: Each user only sees their own cart items
- **Product details**: Fetches complete product information including business names
- **Error handling**: Graceful handling of network errors and edge cases

### Cart Operations
1. **Add to Cart**: Adds new item or increases quantity of existing item
2. **Update Quantity**: Modifies quantity of existing cart item
3. **Remove Item**: Completely removes item from cart
4. **View Cart**: Comprehensive cart view with all items and totals

## Usage

The cart system is automatically available throughout the app via the `useCart()` hook:

```tsx
import { useCart } from '@/context/cart-provider';

function SomeComponent() {
  const { cartItems, addToCart, getTotalItems } = useCart();
  
  // Use cart functionality
}
```

## Database Relationships

- `cart_items.user_id` → `users.id` (User who owns the cart)
- `cart_items.product_id` → `product.id` (Product in the cart)

The foreign key constraints ensure data integrity and cascade deletions appropriately.
